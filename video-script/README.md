When a locked script and the code disagree, the script wins.

Once narration is marked **APPROVED NARRATION — LOCKED**, the wording is
immutable unless Ahmad reopens it. Beats, timing, components, camera moves and
animation adapt around the narration — they never rewrite it.

Rejected alternate scripts are not kept in the working branch. Git history is
the archive.
