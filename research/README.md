# Research

Research supports the script; it is not the script.

## How this folder is organised

Two kinds of research live here, and they age differently.

**Subject research** belongs to one film. It is the factual ground its script
stands on, and it goes stale only if the underlying facts change.

**Method and field research** is shared by every film. It governs how a section
teaches and whether anyone is still watching when it does.

## Rules

- A figure that is not in a `GROUND_TRUTH.md` does not go on screen.
- Version-specific research that has been superseded belongs in `archive/`. Do
  not use an older `V*` file as current evidence merely because it exists.
- Where a source could not be verified, the file must say so in the same line
  as the figure. An unmarked number is treated as verified by everyone who
  reads it later, including you.
