# Production sound effects

Chosen production SFX live here with provenance.

- `MANIFEST.md` — human-readable sound inventory/usage notes.
- `freesound.jsonl` — source/provenance records.
- `.wav` files — selected/processed production sounds.

Do not add an effect without checking its license/provenance. Raw candidate pools are ignored and should not be committed. See `../../docs/SOUND.md` and `../../THIRD_PARTY.md`.
