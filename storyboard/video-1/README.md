# The 18 Billion Mystery — storyboard

This folder contains only the current whole-film storyboard material.

- `STORY_SPINE.md` — promise, causal chain and ending
- `BOARD.md` — generated beat-by-beat board from executable `beats.ts`
- `VOCABULARY_LEDGER.md` — terminology and reveal discipline

Per-section narration and detailed visual contracts live in `video-script/video-1/`.

Old storyboard exports and rejected cuts are intentionally absent. Regenerate current frames from the executable build with `npm run frames:all` and contact sheets with `npm run sheet -- --section=section-NN`.
