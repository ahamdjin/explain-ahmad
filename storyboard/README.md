# storyboard/

The bridge between script and implementation: story structure, section handoffs
and the visual plan.

| folder | what it is | status |
| --- | --- | --- |
| **`video-1/`** | **The 18 Billion Mystery** | built — 13 sections, 173 beats, gates passing |
| **`video-2/`** | **It Replaced Its Replacement** (working title) | spine only — no sections built |

Each folder's `STORY_SPINE.md` is the authority for what that video argues and
in what order. `skills/STORY_STRUCTURE.md` is the gate both must pass: a spine
without a **want**, a **wall** and a **thesis** is not ready to build against.

Rejected alternate boards are not kept in the working branch. Git history is
the archive.
