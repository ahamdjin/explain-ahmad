# GLM v6 research notes

The redesign uses a few durable teaching principles rather than a visual trend.

## Spatial contiguity
Place words next to the visual/object they explain so the learner does not have to visually search the frame and mentally join distant pieces.

## Signaling
Use visible cues—highlighter, underline, dimming, motion, scale—to show what matters now. The current chapter and current concept must be visually dominant.

## Segmenting
One beat should teach one conceptual change. A new sentence in narration does not automatically mean a new page/world.

## Coherence
True but irrelevant facts can still hurt understanding. Keep only details that serve the current explanation or that are intentionally planted for a later beat.

## Pre-training
Before using technical terms such as parameter, active, token, embedding, router and expert, give a short plain-language meaning or a concrete visual role.

## Explorable explanations
Use animation for temporal relationships and interactivity for processes/systems. Do not turn the explanation into a slideshow where clicking is the only meaningful action.

## Applied to this video
- Introduce the model in plain language before dissecting it.
- Highlight Total Parameters and Active Parameters as the opening puzzle.
- Introduce the full Text → Output journey at a readable scale, then morph it into persistent chapter navigation.
- Type the actual example in the chat input, send that same object, show processing, then enter the model through that processing state.
- Carry the same token/embedding actor forward rather than recreating it at every beat.
