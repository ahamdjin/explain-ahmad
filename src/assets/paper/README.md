# Paper Explainer Asset Kit

Small reusable illustrated assets for the GLM paper-world art direction.

These assets provide personality; code provides layout, mechanisms, selection logic, and animation.

## Current characters

- `narrator-curious.svg` — persistent helper / viewer surrogate
- `expert-neutral.svg` — generic specialist
- `expert-confused.svg` — inactive / questioning specialist
- `expert-sleepy.svg` — inactive / waiting specialist
- `expert-selected.svg` — active selected specialist
- `shared-expert.svg` — always-on shared specialist
- `router.svg` — routing dispatcher character

## Rules

1. Do not create hundreds of unique characters. Reuse these with small code-driven rotation, position, scale, badge, and accent variation.
2. Do not use the characters as decoration. Expressions should communicate system state.
3. Keep faces extremely simple. Medium cute, not mascot-heavy.
4. Preserve dark imperfect ink outlines and warm paper fills.
5. Motion should be purposeful: enter, point, wake, select, move, settle.
6. Mechanism visuals such as grids, routing lines, RAM/storage, highlights, and labels should remain code-driven whenever practical.

## Production principle

**Illustrate personality. Code choreography.**

The approved storyboard is the composition reference. Any coded scene should be compared against that frame before production continues.
