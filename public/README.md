# Public runtime assets

Files here are served directly by the Vite app.

`vo/` is the local voice-over drop location. Large VO/audio and final mixes are intentionally ignored by Git; see `vo/README.md`, `../docs/VOICE_OVER.md` and `../docs/SOUND.md`.

Do not commit generated renders or private/local production media here just because the browser can serve them.
