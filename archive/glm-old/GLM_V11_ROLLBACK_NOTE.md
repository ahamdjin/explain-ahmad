# GLM v11 Rollback Note

The v11 Ncase narrative pass introduced a second positioning/layout layer on top of the already-composed 16:9 production scene. That caused questions and causal cues to drift away from the objects they were meant to explain and broke spatial alignment.

The production route has been restored to the previous stable composition.

The Ncase research and narrative-planning documents remain in the repository and should still guide future explanation work.

## Rule for the next narrative pass

Do not add a global overlay system for QUESTION / BUT / THEREFORE / ANSWER.

Instead, each teaching improvement must be integrated into the existing visual object that creates the question or answer:

- question beside the object that creates the headache;
- answer where the mechanism visibly resolves it;
- prediction inside the same coordinate system as the reveal;
- no detached absolute-positioned narrative cards;
- no new layout layer over a finished composition;
- preserve the stable 16:9 geometry first.

The teaching logic should improve without changing spatial composition unless the scene is deliberately redesigned and visually QA'd.
