# GLM v11 Fix Plan

The production visual composition is restored before any new Ncase narrative changes are attempted.

Future narrative improvements must be integrated locally into the stable scene rather than added as a second overlay system.

## Non-negotiable checks

- question stays physically beside the object that creates the question
- answer appears where the mechanism resolves it
- prediction and reveal use the same visual space
- no detached absolute-positioned narrative strips
- no layout-wide CSS overrides without visual QA
- preserve actor continuity and the existing safe frame
- Ncase rules should shape sequencing and causality, not become visible UI labels everywhere
